# DelftDashboard Model Database Toolbox

A DelftDashboard toolbox for managing collections of pre-built model domains.

## Features

- Browse and view existing model domains on the map
- Add new model domains to the database
- Generate domain databases from collections of model files

## Installation

```bash
pip install git+https://github.com/your-org/delftdashboard-model-database-toolbox.git
```

Auto-discovered by DelftDashboard via entry points.
